How to read this dashboard

Board: the table above, ranked by implied launch value (not TVL). Detail view: click any row — it shows the protocol's TVL history, the model breakdown and a farm plan. Filtered view: pick a category or a chain above, or type in the search box — the table narrows to matching rows and the heading counts them.

Model (all inputs come from the snapshot only)

Implied value = max(TVL, $50M) x category multiple x momentum x chain diversity. The category multiple is the median circulating-market-cap / TVL of live protocols in that category (DefiLlama public data, 2026-11-19; categories with fewer than 3 live samples use the global median 0.279x; multiples are clamped to 0.2x–10x). Momentum = 1 + 0.25 x 1d growth + 0.25 x 7d growth + 0.5 x 30d growth, clamped to 0.5x–2.0x. Diversity = 1 + 0.05 per extra chain, capped at 1.5x. No protocol names are hardcoded into the model — every input is a snapshot number.

Pre-token filter

A protocol counts as pre-token when its gecko_id and symbol are both empty, its category is not Bridge, Wrapped Token, Liquid Staking or Restaking, its name does not end with a version marker, contains no whole word wrapped / staked / staking, and does not start with an exchange brand name. Farm plans are generic guidance for positioning, not a promise of a token or an airdrop.
